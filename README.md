# MastersHall

## Requirements

- Visual Studio 2022 — version 17.14 or higher
- .NET SDK 10
  - Download from: [dotnet.microsoft.com](https://dotnet.microsoft.com/en-us/download/dotnet/10.0)
- MonoGame Framework C# project templates (Visual Studio extension)

> **Note:** This project currently targets .NET 9. Ensure your environment includes the .NET 9 runtime SDK as required by the project.

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/chillcatsolutions/MastersHall.git
   cd MastersHall
   ```

2. Open the solution in Visual Studio 2022.
3. Restore NuGet packages (Visual Studio will typically do this automatically).
4. Build and run the project.

## Extensions / Tools

- MonoGame Framework C# project templates — required to create and run the MonoGame project.

## Notes

- If you encounter issues building or running, verify your SDK versions and installed workloads in Visual Studio.
